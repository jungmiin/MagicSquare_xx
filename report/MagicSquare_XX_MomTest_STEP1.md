# MagicSquare_XX — Mom Test STEP 1 보고서

**작성일:** 2026-06-10  
**방법:** Rob Fitzpatrick Mom Test 스타일 인터뷰  
**프로젝트:** 4×4 부분 마방진 (ECB 패턴 과제)

---

## 1. 페르소나

4×4 **부분 마방진**을 손으로/코드로 다루는 **학습자**  
(ECB 패턴 기반 마방진 과제 — 4×4 격자, `?` 2칸, 합 34 조건)

---

## 2. 인터뷰 답변 (과거 사실)

| # | 사실 |
|---|------|
| 1 | 새 마방진을 **발명**하려던 게 아니라, **일부만 채워진 격자**가 유효한지 **손으로 검산**하면서 빈칸을 **논리적으로 채우려** 했다. |
| 2 | 목표는 “이 배치가 말이 되는지”, “1~16 **중복 없이** 합 **34** 조건을 만족하는지” 확인하는 것이었다. |
| 3 | **맨 처음** 한 일: **거의 다 찬 행 하나**를 골라 **남은 숫자를 역산**했다. (중복 확인·후보 정리는 그다음) |
| 4 | **첫 행 역산은 맞았다.** 틀린 건 **다른 줄과의 충돌**이었다. |
| 5 | 충돌 발견: **다른 행 빈칸 역산** 중 **같은 숫자가 다시 필요**해지는 순간 알아챘다. (열·대각선 깊은 확인 전) |
| 6 | 충돌 직후: **재확인 → 문제 행 표시 → 중복 숫자 지움 → 부분 백트래킹**(전체 리셋 아님). |
| 7 | **끝까지 풀지 못하고 포기**했다. |
| 8 | 포기 이유: 백트래킹 지점이 **불명확**해져 부분 수정을 **더 이상 신뢰할 수 없**었다. |
| 9 | 격자 상태: **지운 자국, X, `?` 후보, 체크 후 취소 숫자**가 섞여 **주어진 값 vs 추론값** 구분 불가. |
| 10 | 포기 직전: 격자 옆 **X** + **“처음부터 다시”** 적음 → **실제로 다시 시작하진 않고** 멈춤. |
| 11 | 멈춘 이유: 계속하면 **검산이 아니라 오염된 기억으로 억지 수정**하는 것 같아서. |
| 12 | **손으로는 약 30분** 만에 포기했다. |
| 13 | **나중에 제대로 다시 풀지는 않았다.** |
| 14 | 슬라이드 과제: **실패 과정을 설명**하려다가 **코드 검증기로 방향을 바꿨다.** |
| 15 | 코드에서는 **“부분 상태를 어디까지 유효하다고 볼 것인가”** 에서 막혔다. |
| 16 | **전체 시간 비용: 대략 45~60분.** |

---

## 3. 표면 문제 (잘못된 정의)

> Mom Test에서 **믿지 말고 기록만** 하는 구간. “~~프로그램/기능을 만든다” 류.

- “**주어진 값이랑 추론한 값을 구분**할 수 있어야 해.”
- “**백트래킹 지점**이 명확해야 해.”
- “**처음부터 다시** 시작할 수 있어야 해.”
- “실패 과정 **설명**을 만들어야 해.”
- “**코드 검증기**로 바꾸면 해결될 것 같아.”
- “**부분 상태 유효 범위**를 코드로 정의하면…”
- “Cell **state** 필드로 고정값 vs 입력값 나누면…”
- “**백트래킹 지점**을 명확히 잡는 프로그램/로직을 만든다.”

---

## 4. 진짜 문제 (한 문장)

> 불편·비용·판정·재현 중심, 솔루션 이름 없음.

**4×4 부분 마방진을 체계적으로 풀고 검증하는 절차 없이 검산·추론하다 보니, 어느 시점의 부분 상태까지 믿을 수 있는지 판정하지 못해 수정이 오염되고, 30분~1시간을 쓴 뒤에도 결과를 재현·신뢰할 수 없어 중단하게 된다. 결국 핵심 문제는 **어떻게 풀고 검증할지 그 방법 자체가 명확하지 않았던 것**이다.**

---

## 5. Mom Test 증거 (인용 3줄)

1. “지운 자국, X 표시, 물음표 붙은 후보, 체크했다가 취소한 숫자들이 한 격자 안에 섞여 있어서 **어디까지가 문제에서 주어진 값이고 어디부터가 내가 추론한 값인지 구분 안 되는** 상태”

2. “현재 상태에서 계속하면 **검산이 아니라 오염된 기억으로 억지 수정**하는 게 될 것 같아서 멈췄다.”

3. “코드에서는 **‘부분 상태를 어디까지 유효하다고 볼 것인가’에서 막혔**다.”

---

## 6. Mom Test 메모

| 관찰 | 의미 |
|------|------|
| 손 30분 → 포기, 이후 **재시도 없음** | “나중에 풀겠다”가 아니라 **신뢰 상실**이 핵심 |
| 실패 **설명** → **코드 검증기** 전환 | 막힌 불편(상태 신뢰)을 **기능/도구**로 옮기려는 신호 → 표면 문제로 분리 |
| 손·코드 **같은 막힘** | “주어진 vs 추론” (손) ≈ “부분 상태 유효 범위” (코드) — **동일 본질** |
